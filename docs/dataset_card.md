## TF-IDF + Logistic baseline (Lab 6)

Для задачі класифікації частин мови (upos) було побудовано baseline-модель
на основі TF-IDF та Logistic Regression.

Використано два варіанти:
- Baseline 1: тільки token (unigram)
- Baseline 2: token + lemma (unigram + bigram)

Основні результати:
- Accuracy: до ~0.82
- Macro-F1: до ~0.69

Виявлені проблеми:
- модель часто переоцінює клас PUNCT
- короткі токени (1–2 символи) важко класифікуються
- присутній дисбаланс класів
- відсутній контекст (модель бачить лише окремий токен)

Основні ризики:
- overlap класів (наприклад, службові слова)
- noisy tokens (числа, назви брендів)
- дисбаланс даних
- відсутність контексту

Подальші кроки:
- використання char n-grams
- додавання контекстних ознак
- балансування класів
## Lab7 Observations (SVM + Char-ngrams)

### Class imbalance
Присутній.
Клас PUNCT домінує та часто передбачався помилково (high false positive rate у baseline).

### Noisy data
Є:
- числові токени (116, 41-а)
- змішані формати (AliExpress)
- іноземні слова

Це впливає на якість word-based моделей.

### Char-ngrams effect
Char-ngrams (3–5) дали значне покращення:
- краще обробляються варіації написання
- менше помилок на noisy токенах
- покращення Macro-F1 (~+0.12 від baseline)

### Most problematic class
PUNCT:
- у baseline мав дуже високий recall і низький precision
- модель "перетягувала" багато токенів у цей клас

### Precision / Recall trade-off
Обрано баланс precision/recall:
- зменшено false positives для PUNCT
- збережено достатній recall

Threshold підбирався на validation.
### Лабораторна 8: NLP-аналітика парламентських стенограм

Мета: Дослідити тематичну структуру виступів народних депутатів України за допомогою методів тематичного моделювання (LSA, LDA).
Дані: Стенограми засідань Верховної Ради України, попередньо лемматизовані та очищені від службових слів.
Методи:
LSA (Latent Semantic Analysis) – для виявлення основних концептуальних тем і патернів співзвучності слів.
LDA (Latent Dirichlet Allocation) – для ймовірнісного розподілу тем у документах та виділення найбільш характерних слів для кожної теми.
Результати:
Визначено топ-5 тем у текстах стенограм.
Здійснено порівняння тем, отриманих LSA та LDA, за ключовими словами та семантичним змістом.
Виявлено, які депутати та фракції найчастіше піднімають певні теми.
Висновки: Лабораторна дозволяє інтегрувати методи NLP для аналізу політичних текстів, виділяючи головні тематичні напрями обговорень та взаємозв’язки між учасниками засідань.
## Word Embeddings (Lab 9)

У межах ЛР9 корпус було додатково використано для тренування word embeddings (Word2Vec та FastText).

## Оцінка придатності корпусу для embeddings
Корпус: парламентські стенограми (lemma_text)
Тип тексту: формалізований політичний дискурс
Розмір: достатній для базового навчання embeddings
Домени: законодавчий процес, голосування, парламентські процедури
## Особливості корпусу

Позитивні:

велика кількість повторюваних доменних термінів
стабільна структура (проекти, постанови, голосування)
чітка тематична область

Негативні:

шаблонні фрази (службова мова)
велика частка stopword-like конструкцій
імена/прізвища депутатів створюють шум
частина слів має низьку семантичну інформативність
## Морфологія та шум
українська морфологія присутня у різних формах
є варіативність форм слів (FastText має перевагу)
присутні трансліт/імена/скорочення
## Висновок

Корпус частково придатний для embeddings:

добре працює для доменної лексики (закон, постанова, комітет)
слабше працює для загальних або персональних слів
FastText більш стабільний через морфологічну обробку
## ЛР10 — NER аналіз корпусу

### Тип корпусу
Парламентські стенограми українською мовою.

### Особливості
- довгі складні речення
- розмовно-офіційний стиль
- багато юридичних і політичних термінів

### Важливі сутності
- ORG: державні органи
- PERSON: політики
- LAW / постанови
- числа (CARDINAL)

### Проблеми для NER
- домен сильно відрізняється від новин
- багато шумних конструкцій
- складні межі сутностей

### Висновок
Стандартний spaCy NER працює частково, але потребує rule-based доповнення для доменної точності.
