# Audit Summary — ЛР10

## 1. Pipeline
spaCy pretrained NER + rule-based layer

## 2. Корпус
Парламентські стенограми (processed_v2)

---

## 3. Важливі сутності
- ORG (державні органи)
- PERSON (політики)
- CARDINAL (числа)
- DATE

---

## 4. Baseline проблеми
- false PERSON
- пропущені ORG
- слабка доменна адаптація

---

## 5. Додані правила
- regex для чисел
- патерни для державних органів

---

## 6. Покращення
- кращі ORG
- стабільні CARDINAL
- менше пропусків у структурних сутностях

---

## 7. Залишкові проблеми
- boundary errors
- семантична плутанина
- доменний mismatch

---

## 8. Висновок
Hybrid підхід частково покращує extraction, але pretrained NER потребує доменної адаптації.
