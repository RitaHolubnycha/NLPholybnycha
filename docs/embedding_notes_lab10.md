# ЛР10 — Notes (NER pipeline + hybrid rules)

## 1. Використаний pipeline
Використано готову NER-модель spaCy (pretrained).

## 2. Корпус
Парламентські стенограми (processed_v2).
Тип тексту: офіційні виступи + законодавчі обговорення.

## 3. Підтримувані сутності в spaCy
- PERSON
- ORG
- GPE
- DATE
- CARDINAL
- NORP

## 4. Доменно важливі сутності
- Верховна Рада, Кабінет Міністрів (ORG)
- РНБО, міністерства (ORG)
- закони, постанови (LAW-like)
- числа (CARDINAL)

## 5. Проблеми baseline
- хибні PERSON на фразах
- плутанина ORG/PERSON
- слабке розпізнавання доменних органів

## 6. Додані правила
- regex для чисел (CARDINAL)
- шаблони для державних органів (ORG)

## 7. Що покращилось
- точніше виділення ORG
- стабільніше виділення чисел

## 8. Що не вирішено
- boundary errors
- semantic noise
- domain mismatch

## 9. Висновок
Hybrid підхід частково покращує якість, але pretrained NER не адаптований під парламентський корпус.
