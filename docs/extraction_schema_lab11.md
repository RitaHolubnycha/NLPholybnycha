# Схема вилучення — ЛР11

## Завдання
Структуроване вилучення інформації з парламентських текстів.

## Поля JSON

- persons — список персон (PERSON)
- orgs — організації (ORG)
- locations — геополітичні об’єкти
- legal_acts — закони, постанови, проєкти
- dates — роки або дати у форматі YYYY

## Обов’язкові поля
Усі поля обов’язкові та мають бути списками.

## Обробка відсутніх значень
Якщо сутностей немає → порожній список []

## Особливості корпусу
- політичні виступи
- розмовна офіційна мова
- багато абстрактних речень
- низька щільність явних сутностей

## Примітка
Схема використовується для перевірки структурної коректності виходу LLM.
