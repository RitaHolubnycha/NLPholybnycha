### Audit Summary — Lab 9
# Корпус

Парламентські стенограми (lemma_text)

# Моделі
Word2Vec
FastText
# Найкращі приклади
закон → внесення, зміна, кодекс
постанова → розгляд, прийняття, регламент
фракція → партія, депутатський, група
# Слабкі приклади
україна (Word2Vec) → шумні політичні слова
рішення → частково розмиті сусіди
голосування → інколи надто загальні зв’язки
# Доменні терміни
закон — добре структурований
постанова — стабільний
комітет — чітко доменний
фракція — політично релевантний
голосування — процедурний, але іноді шумний
# Порівняння моделей

FastText виграв у:

рідкісних словах
морфології
noisy варіантах

Word2Vec виграв у:

стабільних частотних термінах
простих семантичних зв’язках
# Висновок

Embeddings у цьому корпусі:

частково корисні
добре працюють у доменній лексіці
обмежені через шум і службові конструкції

FastText є більш практичним вибором для українського парламентського тексту.
