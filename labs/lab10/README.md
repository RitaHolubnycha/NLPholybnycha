# ЛР10 — NER pipeline + hybrid rules

## Мета
Перевірити роботу pretrained NER на парламентському корпусі та покращити результат rule-based підходом.

---

## Використані інструменти
- spaCy NER pipeline
- regex правила
- rule-based extraction

---

## Корпус
processed_v2 (парламентські стенограми)

---

## Baseline (spaCy)
- добре: GPE, DATE
- погано: ORG у домені
- часто помилково визначає PERSON

---

## Hybrid підхід
Додано:
- правила для чисел (CARDINAL)
- шаблони державних органів (ORG)

---

## Результати
- покращено ORG сутності
- покращено числові значення
- частково зменшено пропуски

---

## Висновок
Hybrid підхід покращує якість, але не усуває проблему доменного mismatch.
