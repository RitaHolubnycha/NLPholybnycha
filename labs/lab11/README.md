# Лабораторна робота 11 — LLM Extraction (schema-first)

## Мета
Побудувати надійний pipeline структурованого вилучення даних із перевіркою JSON-схеми та механізмом виправлення помилок.

---

## Основні етапи

1. Вилучення інформації з тексту
2. Перевірка JSON через schema validator
3. Семантична перевірка результату
4. Repair loop (виправлення помилок)
5. Обчислення метрик

---

## Метрики

- структурна валідність
- семантичне покриття

---

## Результати

- структурна валідність: 1.0
- семантичне покриття: ~0.31

---

## Висновок

Schema-first pipeline є стабільним, але обмеженим у семантичному вилученні без більш потужної моделі.
