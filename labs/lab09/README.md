### Lab 9 — Word Embeddings
# Мета

Аналіз word embeddings (Word2Vec, FastText) на парламентському корпусі та порівняння моделей через nearest neighbors.

# Корпус

Парламентські стенограми (lemma_text, очищений варіант)

# Моделі
Word2Vec (skip-gram)
FastText (skip-gram)
# Аналіз

Було виконано:

nearest neighbors для 10 слів
аналіз 5 доменних термінів
5 кейсів “корисно / некорисно”
порівняння моделей
# Ключові результати
закон → стабільна семантична група
постанова → сильна узгодженість моделей
україна → шум у Word2Vec, стабільніше у FastText
фракція → добре структурована політична кластеризація
# Висновок

FastText є більш придатним для корпусу через:

морфологічну варіативність української мови
шумні дані (імена, службові конструкції)

Word2Vec корисний для базових частотних семантичних зв’язків.
